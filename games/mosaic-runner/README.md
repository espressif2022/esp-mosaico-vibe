# Mosaic Runner

An original Apache-2.0 pixel platform game used to verify the MicroPixel PC loop.
Move with A/D or arrows, jump with Space/Up, and restart with R. Mouse/touch uses
the lower-left, lower-middle, and right-side jump zones. No third-party game code,
names, or artwork are included.

`tools/generate_atlas.py` deterministically generates the original player atlas; use `--check` in tests.
