# MicroPixel Host product profile

This directory owns the ESP-Mosaico Vibe product lock and, in later phases,
the Recovery-first partition and build profile for MicroPixel Host.

MicroPixel source remains in `submodule/micropixel`. Do not copy its firmware,
Guest SDK, ABI, or build tools into this directory.

The current phase supports offline Guest creation and Bundle builds only. It
does not yet install MicroPixel Host or game Bundles on a device.
